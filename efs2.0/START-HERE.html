Existing system update

பழைய system-ஐ update செய்ய: RELEASE-2.0G.md. Existing database configuration-ஐ வைத்திருக்கவும். கீழே உள்ள setup steps புதிய installation-க்கு மட்டும்.

Ezy EFSFILLING SYSTEMXAMPP / MYSQL EDITION · 1.4.0

START HERE · முதலில் இதைப் படியுங்கள்

உங்கள் PC-ல் EFS run செய்ய.

இந்த ZIP-ல் PHP, HTML, CSS, JavaScript மற்றும் MySQL SQL files இருக்கின்றன. XAMPP install செய்த PC-ல் கீழே உள்ள steps மட்டும் செய்யுங்கள்.

ஏற்கெனவே EFS 1.3.0 பயன்படுத்தினால்: config/database.php-ஐ வைத்துக்கொண்டு source files update செய்யுங்கள். Existing database-க்கு fresh SQL import வேண்டாம். முழு வழிமுறை: WORKSPACE-UPGRADE-TAMIL.md.
01

ZIP → Extract All

Download செய்த ZIP file-ஐ right-click → Extract All. ZIP-க்குள் இருந்தபடியே file-ஐ open செய்ய வேண்டாம்.

02

efs folder → htdocs

Extract செய்த efs folder-ஐ உங்கள் XAMPP-ன் htdocs folder-க்குள் copy செய்யுங்கள்.

C:\xampp\htdocs\efs\index.php

index.php, setup.php, mysql, app, assets எல்லாம் அந்த efs folder-க்குள் இருக்க வேண்டும்.

03

Apache + MySQL → Start

XAMPP Control Panel திறந்து Apache → Start, MySQL → Start செய்யுங்கள். இரண்டும் running ஆக இருக்க வேண்டும். PHP தனியாக install செய்யத் தேவையில்லை.

04

Browser-ல் இந்த address திறக்கவும்

http://localhost/efs/

Chrome / Edge address bar-ல் இதை type செய்து Enter அழுத்தவும். PHP file-ஐ Desktop-ல் double-click செய்து run செய்ய முடியாது.

Apache 8080 port-ல் இருந்தால்: http://localhost:8080/efs/.

05

Setup → உங்கள் account உருவாக்கவும்

Fresh XAMPP-ல் கீழே உள்ள database settings-ஐ அப்படியே பயன்படுத்தலாம்:

FieldValue
MySQL host / port127.0.0.1 / 3306
Database / usernameefs / root
MySQL passwordPassword set செய்யவில்லை என்றால் காலியாக விடுங்கள்.

பின்னர் station name, உங்கள் பெயர், EFS username, EFS password கொடுங்கள். EFS password குறைந்தது 10 characters.

Empty station: உங்கள் station-ஐ அமைக்க. Demo station: sample data-வுடன் test செய்ய.

Install & open EFS → Open EFS workspace → நீங்கள் உருவாக்கிய account-ல் login.

SQL import கட்டாயமில்லை. Setup database மற்றும் எல்லா tables-ஐயும் உருவாக்கும். Manual import வேண்டுமென்றால் mysql/efs.sql file இருக்கிறது; முழு வழிமுறை README-TAMIL.md-ல் உள்ளது.

பிரச்சினை வந்தால்

Object not found / 404

C:\xampp\htdocs\efs\index.php இருக்கிறதா பார்க்கவும். Double folder htdocs\efs\efs\ வராமல் பார்த்துக்கொள்ளுங்கள். URL-ல் folder name சரியாக இருக்க வேண்டும்.

MySQL connection error / password error

MySQL running என்பதை உறுதி செய்யுங்கள். உங்கள் MySQL port அல்லது password மாறியிருந்தால் setup-ல் சரியான விவரங்களைக் கொடுங்கள். Setup முடிந்த பிறகு connection details config/database.php-ல் இருக்கும்.

PHP version / extension error

64-bit PHP 7.4 அல்லது PHP 8.x தேவை; PHP 8.2+ recommended. pdo_mysql enabled ஆக இருக்க வேண்டும். PHP 5.x / 7.0–7.3 இந்த package-ஐ run செய்யாது. எல்லா PHP versions-க்கும் guarantee கிடையாது.

Visual Studio-ல் எப்படி open செய்வது?

efs folder-ஐ editor-ல் open செய்து source edit செய்யலாம். Run செய்வது XAMPP + browser மூலமாகத்தான். Visual Studio version மாற்றத் தேவையில்லை.

Data / backup எங்கே?

Sales data MySQL server-ல் இருக்கும். EFS Settings-ல் SQL backup create/download செய்யலாம்; copies var/backups-ல் இருக்கும். Restore செய்ய புதிய empty database-க்கு backup import செய்து connection config மாற்றுங்கள். Existing database-ஐ delete / overwrite செய்ய வேண்டாம்.

என் பழைய SQLite data இதிலே வருமா?

இது புதிய MySQL installation. பழைய SQLite database automatic-ஆ convert செய்யப்படாது. Original files மற்றும் business database-ஐப் பாதுகாப்பாக வைத்திருங்கள்.
